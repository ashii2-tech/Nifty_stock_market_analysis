# 📊 Nifty 50 Stock Market Analysis

## 📌 Project Overview

This project analyzes **Nifty 50 stock market data** to identify trends, compare stock performance, evaluate risk, and support data-driven investment screening.

The project combines **Python for data cleaning and preprocessing** with **Power BI for interactive data analysis and visualization**.

The final dashboard provides a consolidated view of stock performance, volatility, sector-wise trends, and an **Investment Score** to help identify potentially attractive stocks for further research.

---

## 🎯 Objectives

* Analyze Nifty 50 stock market data.
* Clean and preprocess raw financial data using Python.
* Analyze stock returns and volatility.
* Compare stocks across different sectors.
* Identify stocks with relatively strong investment scores.
* Analyze trading volume and market activity.
* Build an interactive Power BI dashboard.
* Create a data-driven stock screening framework for future investment research.

---

## ⭐ Investment Score

A custom **Investment Score** was created in Power BI using multiple financial indicators.

The scoring framework considers factors such as:

* Return
* Volatility
* Beta
* P/E Ratio
* Dividend Yield

The objective is to give relatively higher scores to stocks showing a combination of:

**Higher return + Lower volatility + Favorable financial characteristics**

The score is intended as a **screening and comparison tool**, not as a guaranteed prediction of future stock performance.
